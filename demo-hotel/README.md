# Светлые Сны — сервис бронирования номеров (PHP + PDO, шаблон Bootstrap)

Корень сайта — папка `public/`. Код и база лежат в `app/` (вне корня).

## Запуск
**Вариант 1 — встроенный сервер PHP (php 8.0+ с pdo_sqlite):**
    php -S localhost:8000 -t public
    # откройте http://localhost:8000 (главная), /catalog.php — каталог
База SQLite (`app/hotel.db`) создаётся и заполняется автоматически.

**Вариант 2 — XAMPP + MySQL:**
1. Скопируйте проект в `C:\xampp\htdocs\sladkie-sny`, запустите Apache и MySQL.
2. В phpMyAdmin импортируйте `database_mysql.sql`.
3. В `app/config.php` поставьте `DB_DRIVER = 'mysql'` (при необходимости поправьте логин и пароль).
4. Откройте http://localhost/sladkie-sny/public/

Админ-панель: `login.php` (логин hotel123, пароль adminHotel).

Безопасность: подготовленные запросы PDO, экранирование вывода, CSRF-токены, CSP, серверная валидация и фильтрация,
блокировка перебора пароля (5 попыток / 5 минут), смена идентификатора сессии при входе.

## Что внутри (по заданию)
- Задание 1: диаграммы в папке `docs/` — `usecase.png` (прецеденты) и `classes.png` (классы), исходники в `.svg`.
- Задание 2: `index.php` — главная (шапка с названием и слоганом, подвал с контактами); `catalog.php` — каталог
  (6 случайных номеров, фильтр, «Применить» / «Сбросить фильтр», «Забронировать»); `order.php` — бронирование
  (имя и фамилия — кириллица, пробелы, точки, тире; телефон +7(ХХХ)ХХХ-ХХ-ХХ; e-mail; даты ДД.ММ.ГГГГ).
- Количество случайных номеров меняется константой `CATALOG_LIMIT` в `app/config.php`.
